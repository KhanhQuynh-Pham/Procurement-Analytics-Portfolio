# Procurement KPI Dashboard

## Overview

This project is a Power BI dashboard built to monitor procurement performance for laboratory-related purchases in the pharmaceutical industry. It provides visibility into overall procurement performance, supplier performance, procurement lead time, and delivery risk — enabling data-driven decision-making for procurement and supply chain teams.

The dashboard also served as the analytical foundation for the accompanying **Learning Portfolio**, which walks through a real disruption case (import licensing delays under Vietnam's new Chemical Law) identified using this data.

## Business Objectives

The dashboard was designed to answer the following business questions:

- How much has been spent across different laboratory categories?
- How much savings have been generated compared with budgeted costs?
- Which suppliers and manufacturers account for the highest spend?
- How efficient is the PR-to-PO procurement process?
- Which suppliers are causing delivery delays?
- What are the major supply risks that require attention?

## Key Features

### Overall Performance Dashboard
- Spend and savings analysis by category, manufacturer, and country of origin
- Compliance monitoring
- Open PO monitoring
- PR-to-PO lead time analysis

### Supplier Performance Dashboard
- Delivery status tracking (Early / On Time / Late)
- Overdue PO monitoring
- Risk matrix for supplier performance evaluation
- Supplier benchmarking
